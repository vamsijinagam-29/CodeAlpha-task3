# Design brief — Global Development Data Story

## Theme Name
**Evidence-led editorial dashboard**

## Intro
A calm, high-contrast data story that makes historical global development patterns feel legible and trustworthy.

## Design movement
Editorial information design with a restrained analytical dashboard language.

## Core principles
- Let the data lead; keep decoration subordinate to chart readability.
- Use strong hierarchy: one dark narrative header, compact metric cards, then full-width charts.
- Keep interaction discoverable through Plotly's native controls and hover states.
- Preserve source attribution and limitations visibly, not as hidden documentation.

## Color philosophy
Deep navy anchors the narrative shell; pale slate provides breathing room; continent colors are distinct, accessible, and reused consistently across every chart.

## Layout paradigm
Responsive single-column storytelling with four compact summary cards and stacked full-width visual panels.

## Signature elements
Dark hero band, rounded white chart cards, short analytical titles, and source/limitations notes.

## Interaction philosophy
Quiet, direct, and evidence-first: hover for country detail, legend toggles for continent comparison, zoom for dense scatterplot regions, and animation for the 2007 relationship view.

## Animation
Only the Plotly scatterplot animation is used because it adds analytical meaning across the dataset's time dimension.

## Typography system
System sans-serif stack for fast loading and platform consistency. Large bold display title, compact uppercase labels, readable chart text.

## Brand essence
A portfolio-ready, transparent data story for CodeAlpha Task 3.

## Brand voice
Clear, measured, and practical.

## Wordmark/logo
A navy square icon with a rising three-bar chart symbol, representing a development trajectory.

## Signature brand color
`#172033` (deep navy).
